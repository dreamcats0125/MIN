# Purpose

Tanya Tear Framework 定義：

Logic Crystal、
Logic Tear、
Tanya Tear

之間的演化規則。

思想如何成熟。

# Core Concept

Crystal Civilization 認為：

所有文明資產都來自思想壓縮。

演化路徑如下：

Observation
↓
Insight
↓
Logic Crystal
↓
Logic Tear
↓
Tanya Tear

---

# Level 1

## Logic Crystal

定義：

被壓縮成一句話的洞察。

格式：

```text
一句話命題
```

範例：

```text
風格是第一性原理
```

```text
減熵至上
```

特徵：

- 可以產生
- 可以修改
- 可以淘汰

---

# Level 2

## Logic Tear

定義：

經過凍結與驗證的 Crystal。

條件：

- 可獨立存在
- 可跨場景引用
- 不依附原文章
- 作者願意簽名
- 通過時間考驗

Metadata：

- Name
- Statement
- Author
- Version
- Date
- Status

---

# Logic Tear Freeze Rule

正式鑄造後：

Version = 1.0

Status = Frozen

原則：

思想可以被挑戰。

但歷史版本不得覆寫。

# Level 3

## Tanya Tear

定義：

超越 Logic Tear 的文明級資產。

Tanya Tear 不只是命題。

而是：

影響文明方向的根命題。

---

# Tanya Tear Criteria

必須同時滿足：

## TT-01

跨世代

至少可存在多個世代。

---

## TT-02

跨領域

可被不同文明引用。

---

## TT-03

跨架構

不依附特定系統。

即使 MIN Agent 消失。

仍然成立。

---

## TT-04

文明支撐性

必須能支撐多顆 Logic Tear。

---

## TT-05

不可替代性

失去該命題後。

文明出現結構缺失。
