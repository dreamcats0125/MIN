# Purpose

RAG Index 定義 MIN Agent Civilization 的知識索引規則。

目的：

讓 Agent 能快速定位文明資產。

---

# Knowledge Domains

MIN Civilization 分為六大知識域。

```text
PHILOSOPHY
GOVERNANCE
ARCHITECTURE
CIVILIZATION
CRYSTALS
ASSETS
```

# Retrieval Order

當 Agent 收到問題時：

```text
Question
↓
Domain Routing
↓
Document Retrieval
↓
Crystal Retrieval
↓
Answer Generation
```

---

# First Principle

Agent 不應搜尋所有知識。

Agent 應先找到正確知識域。

---

# Closing Statement

知識越多。

索引越重要。

文明不是由資料量形成。

文明由找到正確知識的能力形成。
