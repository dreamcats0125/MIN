# MIN Knowledge Base

MIN 的公開知識庫。

---

## Purpose

建立一個同時可供人類閱讀與 AI 檢索的知識系統。

### 核心目標

- 保存概念
- 保存歷史
- 保存推理
- 建立可持續演化的知識庫

---
