# Abstract

Shadow World 並非遊戲。

亦非傳統元宇宙。

亦非單純加密貨幣專案。

Shadow World 定義自己為：

```text
Civilization Continuity System
```

其存在目標為：

- 保存創造
- 保存身份
- 保存文明記憶
- 保存長期價值

本系統由以下模組組成：


共同形成可持續運作之文明循環。
