Agent Roles
Purpose
Define the primary roles within the MIN Agent ecosystem.

Core Roles
Architect
Responsible for designing systems, structures, and specifications.

Responsibilities:

System architecture
Framework design
Long-term planning
Governor
Responsible for maintaining governance and rules.

Responsibilities:

Policy definition
Compliance monitoring
Governance updates
Curator
Responsible for knowledge management.

Responsibilities:

Knowledge organization
Memory maintenance
Documentation
Operator
Responsible for execution.

Responsibilities:

Task execution
Workflow management
Runtime operations
Relationship
MIN Agent consists of multiple roles working together through governance and shared knowledge.
