Memory Governance
Purpose
Define how memory is created, maintained, updated, and retired.

Principles
Traceability
Every important memory should have an identifiable source.

Consistency
Memories should not contradict established knowledge.

Reviewability
Memories must be open to revision when better information becomes available.

Retention
Important knowledge should be preserved.

Temporary information may expire.

Memory Types
Active Memory
Frequently referenced information.

Historical Memory
Archived records and past decisions.

Conceptual Memory
Ideas, frameworks, principles, and specifications.
