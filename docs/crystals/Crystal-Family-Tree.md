# Purpose

Crystal Family Tree 用於描述所有 Logic Crystal、Logic Tear、Tanya Tear 之間的演化關係。

其目的不是建立分類學（Taxonomy）。

而是建立：

> 思想如何誕生、壓縮、凍結、升階與文明化。

---

# Evolution Ladder

```text
Observation
    ↓
Insight
    ↓
Logic Crystal
    ↓
Logic Tear
    ↓
Core Logic Tear
    ↓
Sovereign Tear
    ↓
Tanya Tear
```

---

# Level 0 : Observation

定義：

現象。

尚未經過壓縮。

範例：

- 人會重複犯錯
- 團隊會逐漸失序
- AI 會模仿使用者風格

特徵：

- 不具普遍性
- 不可直接傳承
- 不可鑄造

---

# Level 1 : Insight

定義：

對現象產生解釋。

範例：

```text
人會重複犯錯，
因為記憶會衰退。
```

特徵：

- 開始形成概念
- 尚未充分驗證
- 可能失效

---

# Level 2 : Logic Crystal

定義：

經壓縮後可獨立存在的命題。

# Level 5 : Sovereign Tear

多個 Core Tear 的共同根源。

# Level 6 : Tanya Tear

定義：

後天堂時代資產。

超越 Crystal 與 Logic Tear。

用於保存：

- 文明方向
- 宇宙級命題
- 多世代智慧

特徵：

- 不可交易
- 不可估值
- 不可替代

# Crystal Law

第一法則：

```text
所有 Tear 都來自 Crystal。
```

第二法則：

```text
所有 Crystal 都來自 Reality。
```

第三法則：

```text
未完成的思想，
不得稱為 Tear。
```

第四法則：

```text
文明只保存經得起時間的思想。
```

# Closing Statement

Crystal Family Tree 不記錄誰是對的。

它記錄：

思想如何被時間鍛造成文明。

每一顆 Crystal，
都曾經只是一個瞬間的念頭。

而文明，
由那些被保留下來的念頭組成。
